## Uitdagingen & Prestaties

Tijdens UI2 had ik eigenlijk al veel moeilijkheid met typescript, wat vooral kwam doordat ik dit niet echt veel
ge-oefent heb. Hierdoor was het eerste deel van het project, de piggybank, moeilijk. Daarmee ben ik wel een stuk beter geworden in typescript maar react ging nog steeds moeilijk. Ik heb mijn piggybank project maar half afgewerkt en dit betekende dat ik sommige leerstof wat miste voor dat ik aan het examenproject begon. Dit heeft me zeker tijd gekost. 

Ik merk altijd bij mezelf dat UI en design niet echt een sterktepunt is. Dit vind ik duidelijk als je de applicatie opened, ik vind dat die er saai uitziet. Ik zou graag een app hebben die ik echt mooi vind maar vanaf dat ik zelf kleuren of foto's begin toe te voegen vind ik dat het enkel lelijker wordt.

Ik ben het meest trots op mijn cron scheduling, het implementeren hiervan ging heel vlot en de feature die eruit komt is heel krachtig.

## ❌ Onvoltooide / Geplande Functionaliteiten

Momenteel in mijn todo/in progress kolom op het issue bord staat:
- full room controls/full floor controls
  - Ergens stond dat qua UX het intuitief en eenvoudig moet zijn om alle lichten in een kamer of alle verwaming op een verdiep tegelijk aan te passen. Dit is niet echt mogelijk tenzij de admin een scene aanmaakt. Dit zou nog moeten gebeuren
- Scenes zijn een beetje fout geimplementeerd. Het zou moeten werken op basis van een start en eind datum waartussen de controls niet handmatig beheerbaar zijn. Ik heb gewoon een enkel event waarop de domotica naar een bepaalde waarde gezet worden. Je zou 2 scenes kunnen maken voor de start en eind datum maar dan nog kan je als gebruiker de controls veranderen wanneer je wilt.
- de floorplan op mobile is niet gebruikbaar en zou dus weg moeten of verbeterd worden.
